# 🚀 Сервис Автоматических Рассылок (MailingService)

## 🎯 Заголовок: Название проекта и его краткое описание
**Сервис Автоматических Рассылок** — это мощная и гибкая платформа, разработанная на Django, для создания, планирования и управления email-рассылками. Использует Celery для асинхронной обработки и PostgreSQL для надежного хранения данных.

## 📝 Описание: Цель и основные функции проекта
**Цель проекта:** Предоставить пользователям (менеджерам) удобный инструмент для автоматизации маркетинговых и информационных рассылок.

**Основные функции:**
1.  **CRUD-операции:** Полное управление (Создание, Просмотр, Изменение, Удаление) Клиентов, Сообщений и Рассылок.
2.  **Кастомная Аутентификация:** Использование Email для входа и кастомной модели пользователя с полями (аватар, телефон, страна).
3.  **Планирование:** Запуск рассылок по расписанию (ежедневно, еженедельно, ежемесячно) с помощью **Celery Beat**.
4.  **Логирование:** Сохранение детальной информации о каждой попытке отправки (статус, ответ сервера).
5.  **Ролевая модель:** Разделение доступа между обычными пользователями и Менеджерами.
6.  **Мгновенная отправка:** Возможность ручного запуска рассылки через интерфейс или кастомную команду.

## ⚙️ Установка: Инструкции по установке и настройке
### Предварительные требования
* Python 3.10+
* PostgreSQL (запущенный сервер)
* Redis (для работы Celery и кэширования)

### Шаги установки
1.  **Клонирование репозитория:**
    ```bash
    git clone [https://github.com/by-danilov/MailingService.git](https://github.com/by-danilov/MailingService.git)
    cd MailingService
    ```

2.  **Создание и активация виртуального окружения:**
    ```bash
    python -m venv venv
    .\venv\Scripts\activate  # Для Windows (PowerShell)
    # source venv/bin/activate # Для Linux/macOS
    ```

3.  **Установка зависимостей:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Настройка переменных окружения:**
    Создайте файл **`.env`** в корне проекта и заполните его данными для подключения к БД и Email-сервису (например, Яндекс/Mail.ru):
    ```
    SECRET_KEY=ВАШ_ОЧЕНЬ_ДЛИННЫЙ_СЕКРЕТНЫЙ_КЛЮЧ
    DB_NAME=mailing_db
    DB_USER=postgres_user
    DB_PASSWORD=secretpassword
    DB_HOST=localhost
    DB_PORT=5432
    EMAIL_HOST_USER=ваш_ящик@yandex.ru
    EMAIL_HOST_PASSWORD=ваш_пароль_приложения
    CELERY_BROKER_URL=redis://localhost:6379/0
    CELERY_RESULT_BACKEND=redis://localhost:6379/0
    ```

5.  **Миграции базы данных:**
    ```bash
    python manage.py migrate
    python manage.py create_groups # Создаст группу "Менеджеры"
    python manage.py createsuperuser
    ```

## 🚀 Использование: Краткое описание, как пользоваться проектом
### Запуск сервисов
Для полноценной работы необходимы три отдельных процесса:

1.  **Запуск Django сервера:**
    ```bash
    python manage.py runserver
    ```
2.  **Запуск Celery Worker (для обработки задач):**
    ```bash
    celery -A mailing_project worker -l info
    ```
3.  **Запуск Celery Beat (для планирования расписания):**
    ```bash
    celery -A mailing_project beat -l info -S django
    ```

### Основной функционал
1.  **Доступ:** Откройте `http://127.0.0.1:8000/`. Войдите как Суперпользователь или обычный пользователь.
2.  **Создание:** Перейдите в раздел **Сообщения** и **Клиенты**, чтобы создать контент и список получателей.
3.  **Планирование:** Создайте **Рассылку**, выберите сообщение, клиентов и задайте периодичность и время запуска. Celery Beat автоматически начнет отправку, когда наступит время.
4.  **Просмотр результатов:** Раздел **Логи** позволяет отслеживать статус и ответ сервера для каждой попытки отправки.
